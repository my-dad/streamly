# Streamly Home Feed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Home placeholder with the first real MVI screen — a scrollable feed of video cards with category chips, loading/empty/error states, and navigation to the Player.

**Architecture:** `HomeViewModel` exposes exactly `state: StateFlow<HomeUiState>` and `onIntent(HomeIntent)`. One-shot navigation goes out through an effect `Channel`, collected at the `NavDisplay` host — never through state, never as a lambda held by the ViewModel. Domain `Video` is mapped to an `@Immutable VideoUi` with pre-formatted display strings by a pure function, so all formatting is unit-tested rather than asserted by eye.

**Tech Stack:** Compose BOM 2026.02.01 · Coil3 3.5.0 · Hilt 2.60.1 · coroutines-test 1.11.0 · Turbine 1.2.1

**Prerequisites:** the foundation plan and the design-system/Nav3 plan must both be complete. This plan consumes `Video`, `Category`, `HomeFeed`, `AppError`, `GetHomeFeedUseCase`, `ContentState`, and `StreamlyKey`.

## Global Constraints

All constraints from the two preceding plans still apply. Reinforced here because this screen is the template every later screen copies:

- ViewModel exposes **exactly** `val state: StateFlow<XxxUiState>` and `fun onIntent(XxxIntent)`. Nothing else is public.
- Never expose `MutableStateFlow` or a mutable collection from a ViewModel.
- One-shot events (navigation, snackbars) go through an effect `Channel`/`Flow` — never through state, never as lambdas stored in the ViewModel.
- Composables never call repositories, use cases, or Ktor.
- Screen composables are stateless: `(UiState, (Intent) -> Unit)`. Don't pass ViewModels down the tree.
- Collect with `collectAsStateWithLifecycle()` only.
- Lazy lists always set `key = { it.id }`.
- `isLoading`, empty, and error (sealed `AppError`, not a raw String) are modelled inside every `UiState`.
- Reuse `ContentState` for loading/empty/error. Do not hand-roll per-screen variants.
- No hardcoded widths.

**`:core:designsystem`**
- `format/Formatting.kt` — pure display formatters. The heavily-tested unit.

- `ui/home/HomeViewModel.kt`

> **Why `VideoCard` takes primitives:** `VideoUi` lives in `:app`, and `:core:designsystem` cannot depend on `:app`. Passing formatted strings keeps the component reusable and the module graph acyclic.

```kotlin
package io.github.mabrur.streamly.core.designsystem.format

import java.util.Locale

/**
 * Display formatters for feed metadata.
 *
 * Pure and Locale-pinned: [Locale.US] is used deliberately so the decimal separator
 * cannot vary by device and silently break the tests that pin these strings.
 */

fun formatViewCount(count: Long): String {
    val label = when {
        count >= 1_000_000_000 -> compact(count, 1_000_000_000, "B")
        count >= 1_000_000 -> compact(count, 1_000_000, "M")
        count >= 1_000 -> compact(count, 1_000, "K")
        else -> count.toString()
    }
    return if (count == 1L) "$label view" else "$label views"
}

private fun compact(count: Long, unit: Long, suffix: String): String {
    val whole = count / unit
    val tenths = (count % unit) * 10 / unit
    return if (whole >= 10 || tenths == 0L) {
        "$whole$suffix"
    } else {
        String.format(Locale.US, "%d.%d%s", whole, tenths, suffix)
    }
}

fun formatRelativeAge(epochSeconds: Long, nowSeconds: Long): String {
    val elapsed = (nowSeconds - epochSeconds).coerceAtLeast(0)
    return when {
        elapsed < 60 -> "just now"
        elapsed < 3_600 -> plural(elapsed / 60, "minute")
        elapsed < 86_400 -> plural(elapsed / 3_600, "hour")
        elapsed < 2_592_000 -> plural(elapsed / 86_400, "day")
        elapsed < 31_536_000 -> plural(elapsed / 2_592_000, "month")
        else -> plural(elapsed / 31_536_000, "year")
    }
}

private fun plural(value: Long, unit: String): String =
    if (value == 1L) "1 $unit ago" else "$value ${unit}s ago"

fun formatDuration(durationMs: Long): String {
    val totalSeconds = (durationMs / 1_000).coerceAtLeast(0)
    val hours = totalSeconds / 3_600
    val minutes = (totalSeconds % 3_600) / 60
    val seconds = totalSeconds % 60
    return if (hours > 0) {
        String.format(Locale.US, "%d:%02d:%02d", hours, minutes, seconds)
    } else {
        String.format(Locale.US, "%d:%02d", minutes, seconds)
    }
}
```

```kotlin
    val metaLine: String,

    title = title,
    channelName = channelName,
    thumbnailUrl = thumbnailUrl,

)
```

**Interfaces:**
- Consumes: `GetHomeFeedUseCase`, `AppError`, `Category`, `HomeFeed`, `VideoUi.toUi`.
- Produces:
  - `@Immutable data class HomeUiState(isLoading: Boolean = false, videos: List<VideoUi> = emptyList(), categories: List<String> = emptyList(), selectedCategory: String = "All", error: AppError? = null)`
  - `sealed interface HomeIntent { data object Refresh; data class VideoClicked(id); data class CategorySelected(category) }`
  - `sealed interface HomeEffect { data class OpenPlayer(videoId) }`
  - `@HiltViewModel class HomeViewModel` exposing `val state: StateFlow<HomeUiState>`, `val effects: Flow<HomeEffect>`, `fun onIntent(HomeIntent)`.

> **Note on `effects`:** it is a third public member alongside `state` and `onIntent`. The
> project rule "exposes exactly state and onIntent" is about not leaking mutable state or
> repositories; a read-only effect `Flow` is the mechanism the same rules mandate for
> one-shot navigation. `_effects` stays private.

```kotlin
import androidx.compose.runtime.Immutable
import io.github.mabrur.streamly.domain.error.AppError

@Immutable
data class HomeUiState(
    val isLoading: Boolean = false,
    val videos: List<VideoUi> = emptyList(),
    val categories: List<String> = emptyList(),
    val selectedCategory: String = ALL_CATEGORY,

    data object Refresh : HomeIntent

}

    data class OpenPlayer(val videoId: String) : HomeEffect
```

```kotlin
package io.github.mabrur.streamly.ui.home

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import io.github.mabrur.streamly.domain.error.AppError
import io.github.mabrur.streamly.domain.model.Category
import io.github.mabrur.streamly.domain.usecase.GetHomeFeedUseCase
import javax.inject.Inject
import kotlinx.coroutines.channels.Channel
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.receiveAsFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

@HiltViewModel
class HomeViewModel @Inject constructor(
    private val getHomeFeed: GetHomeFeedUseCase,
) : ViewModel() {

    private val _state = MutableStateFlow(HomeUiState())
    val state: StateFlow<HomeUiState> = _state.asStateFlow()

    private val _effects = Channel<HomeEffect>(Channel.BUFFERED)
    val effects: Flow<HomeEffect> = _effects.receiveAsFlow()

    init {
        load(HomeUiState.ALL_CATEGORY)
    }

    fun onIntent(intent: HomeIntent) {
        when (intent) {
            HomeIntent.Refresh -> load(_state.value.selectedCategory)
            is HomeIntent.CategorySelected -> load(intent.category)
            is HomeIntent.VideoClicked -> viewModelScope.launch {
                _effects.send(HomeEffect.OpenPlayer(intent.videoId))
            }
        }
    }

    private fun load(category: String) {
        _state.update {
            it.copy(isLoading = true, error = null, selectedCategory = category)
        }
        viewModelScope.launch {
            val nowSeconds = System.currentTimeMillis() / 1_000
            getHomeFeed(Category(category))
                .onSuccess { feed ->
                    _state.update {
                        it.copy(
                            isLoading = false,
                            videos = feed.videos.map { video -> video.toUi(nowSeconds) },
                            categories = feed.categories.map(Category::name),
                            error = null,
                        )
                    }
                }
                .onFailure { throwable ->
                    _state.update {
                        it.copy(
                            isLoading = false,
                            videos = emptyList(),
                            error = throwable as? AppError
                                ?: AppError.Unknown(throwable.message.orEmpty()),
                        )
                    }
                }
        }
    }
}
```

```kotlin
 * Stateless by construction: a function of [HomeUiState] plus an intent sink.
 * No ViewModel, no repository, no side effects in composition.

fun HomeScreen(
    state: HomeUiState,
    onIntent: (HomeIntent) -> Unit,
    modifier: Modifier = Modifier,

                categories = state.categories,
                selected = state.selectedCategory,

            error = state.error,

            LazyColumn(
```

Create `app/src/main/java/io/github/mabrur/streamly/ui/home/HomeRoute.kt`:

```kotlin
package io.github.mabrur.streamly.ui.home

import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.ui.Modifier
import androidx.hilt.navigation.compose.hiltViewModel
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import androidx.lifecycle.compose.LocalLifecycleOwner
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.repeatOnLifecycle
import androidx.compose.runtime.LaunchedEffect

/**
 * Binds the ViewModel to the stateless screen and drains one-shot effects.
 *
 * Effects are collected inside [repeatOnLifecycle] so a navigation event cannot be
 * delivered while the screen is in the background and arrive against a stale back stack.
 */
@Composable
fun HomeRoute(
    onOpenPlayer: (String) -> Unit,
    modifier: Modifier = Modifier,
    viewModel: HomeViewModel = hiltViewModel(),
) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    val lifecycleOwner = LocalLifecycleOwner.current

    LaunchedEffect(viewModel, lifecycleOwner) {
        lifecycleOwner.lifecycle.repeatOnLifecycle(Lifecycle.State.STARTED) {
            viewModel.effects.collect { effect ->
                when (effect) {
                    is HomeEffect.OpenPlayer -> onOpenPlayer(effect.videoId)
                }
            }
        }
    }

    HomeScreen(state = state, onIntent = viewModel::onIntent, modifier = modifier)
}
```
